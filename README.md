## چرا MarbleDU؟

- 🚫 **VPN لازم نداره.** نه VPN، نه root. فقط همین اپ.
- 📱 **می‌گه کدوم اپ چقدر مصرف کرد.** از بیشترین به کمترین.
- 🕐 **می‌گه از چه ساعتی تا چه ساعتی.** بازه‌های مصرف + ساعت‌های پرمصرف.
- 📶 **اپراتورت رو می‌شناسه – حتی روی وای‌فای.** همراه اول، ایرانسل، رایتل، مخابرات، شاتل و… با نشان رنگی هر کدوم.
- 🗓️ **گزارش کامل ۳۰ روز.** هر روز جدا، با تاریخ شمسی و میلادی، نمودار ۲۴ ساعت، سهم هر اپراتور و هر اپ.
- 🎨 **۸ تم رنگی** و نوار پایین شناور.
- ⚡ **سرعت و پینگ.** لحظه‌ای، میانگین، بیشترین، نوسان و افت بسته.
- 📈 **گزارش می‌سازه.** خروجی CSV و متن آماده برای فرستادن.
- 🔒 **حریم خصوصیت محفوظه.** هیچ آمار مصرفی از گوشی‌ت بیرون نمی‌ره. (فقط برای شناختن اپراتور وای‌فای، یک درخواست «IP من چیه» فرستاده می‌شه که از تنظیمات قابل خاموش کردنه.)

## نصب

1. برو به تب **[Releases](../../releases)**.
2. فایل مناسب گوشیت رو دانلود کن:
   - `arm64-v8a` → تقریباً همه‌ی گوشی‌های امروزی
   - `armeabi-v7a` → گوشی‌های قدیمی‌تر
   - `x86_64` / `x86` → شبیه‌سازها
   - `universal` → مطمئن‌ترین گزینه، کمی بزرگ‌تر
3. نصب کن و اول از همه به اپ اجازه بده **مصرف اپ‌ها** رو ببینه
   (تنظیمات ← دسترسی به داده‌های مصرف ← MarbleDU).

همه‌ی نسخه‌ها با **یک کلید یکسان** امضا می‌شن، پس آپدیت همیشه راحت نصب می‌شه. ✅

## داخل اپ چی هست؟

| صفحه | چی نشون می‌ده |
|---|---|
| **خانه** | مصرف امروز و ۳۰ روز، روند ۷ روزه، اپراتور، سرعت، بازه‌ی فعلی، سقف بسته |
| **زنده** | سرعت دانلود/آپلود همین لحظه، میانگین و پیک، تست پینگ |
| **اپ‌ها** | مصرف هر اپ در امروز / هفته / ماه، جدا برای موبایل و وای‌فای |
| **۳۰ روز** | گزارش کامل هر روز از ۳۰ روز اخیر (شمسی + میلادی): دانلود/آپلود/مجموع، هر اپراتور، هر اپ، نمودار ۲۴ ساعت، خروجی CSV |
| **تنظیمات** | زبان، پوسته، ۸ تم رنگی، طراحی Expressive، **گزینه‌های ویژه‌ی ایران** |

### گزینه‌های ویژه‌ی ایران (در تنظیمات)

شناسایی خودکار اپراتور · گزارش حجم مصرفی · میانگین سرعت · میانگین پینگ ·
نمایش بازه‌های مصرف · تفکیک مصرف اپ‌ها · ساعت‌های پرمصرف · دوره‌ی صورتحساب.
هر کدوم رو خواستی خاموش کن.

### زبان

فارسی (راست‌چین) و English (چپ‌چین). از تنظیمات عوض کن؛ همین‌جا، بدون ری‌استارت.

## ساخته‌شده با

Kotlin · Jetpack Compose · **Material 3 Expressive** · فونت Vazirmatn

بدون VPN و بدون root، آمار شبکه رو مستقیم از شمارنده‌های سیستم می‌خونیم و
مصرف هر اپ رو با `NetworkStatsManager` جدا می‌کنیم.

## برای توسعه‌دهنده‌ها

```bash
./gradlew assembleDebug      # ساخت همه‌ی معماری‌ها
./gradlew test               # تست‌ها
```

- نسخه‌ها همه در `gradle/libs.versions.toml` هستند.
- بعد از هر merge روی `main`، APK همه‌ی معماری‌ها خودکار ساخته و امضا می‌شه.
- هر هفته یک PR خودکار برای آپدیت کتابخانه‌ها ساخته می‌شه.
- تغییرات هر نسخه در [CHANGELOG.md](CHANGELOG.md).

## English (short)

**MarbleDU** shows exactly where your mobile data goes — **without any VPN**.
See per-app usage, usage sessions ("from 09:12 to 11:40"), Iranian carriers
(MCI, Irancell, Rightel…), live/average speed and ping, plus CSV reports.
Fully Persian (RTL) and English (LTR), built with Material 3 Expressive.

Download the APK for your CPU architecture from [Releases](../../releases),
then allow **usage access** in system settings. All builds share the same
signing key, so updates install cleanly.
